# verifier v2 — 预览可用性（2026-08-03）
## 背景
用户反馈：点击预览"卡卡的、看不见、进不去"。v1 只验证了功能正确性，未覆盖冷启动时序。
## v2 新增度量（相对 v1）
1. **首屏秒开**：进程启动后 4s 内 GET / 必须 200（不等待 DB 自举）
2. **平台健康检查零阻塞**：listen 在 bootstrap 之前（api/boot.ts 结构断言）
3. **API 悬挂上限**：DB 不可达时单请求 ≤15s 快速失败（connectTimeout），不得吊死
4. **无端口冲突**：3000 仅生产 dist/boot.js 监听，不得有 vite dev 抢占
5. 沿用 v1 全部功能度量（76 断言/92 量规/30 冒烟/32 角色扮演）
## 根因记录
- 预览环境数据库为 privatelink 内网地址，快照环境可能不可达 → 旧 boot 在 listen 前 await bootstrap，健康检查超时=永远进不去
- 沙箱内多个 vite dev 进程抢占 :3000 → 本地访问被 dev 服务器接管（慢、HMR 卡顿）
