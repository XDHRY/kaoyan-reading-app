# verifier v3 — 复盘定制卷 + 参与式解题（2026-08-03）
## 需求锚点（用户原话拆解）
A. 交卷后（真题/仿真均可）可基于三件套生成全套新模拟题：
   ①本套题的错因分布 ②AI 对本套的诊断分析 ③学生自评（可填可不填）
B. 新模块：参与式解题——学生走进解题每一步，而不是交卷后才见 AI
C. 全局扫描缺陷 + 高价值低风险增强
## 功能度量
F1 复盘定制卷（retroRouter）
- F1.1 交卷后结果区出现「复盘定制卷」卡：错题数>0 可一键生成；自评 textarea 可空
- F1.2 生成输入=本套错题的 errorType 分布 + 每题 AI 诊断摘要(rootCause/distractorPull) + 自评原文
- F1.3 产出=完整 generatedSet（同话题复用 generatedPractice 判分闭环），错题照样入册
- F1.4 幂等：同一 practiceRecord+自评哈希 1 小时内复用，不重复烧 LLM
- F1.5 历史档案可见"定制卷"来源标签
F2 参与式解题（interactiveRouter，新 Tab「跟我练」）
- F2.1 四步逐步走：审题(判题型/定考眼)→定位(学生选段落)→解题(学生选答案)→复盘(学生写一句，AI 对照)
- F2.2 每步先学生作答、后揭示 AI 参照，不剧透下一步
- F2.3 纯前端会话（localStorage 持久化进度，刷新不断线），仅最终成果落库（interactive_records）
- F2.4 真题与仿真题通用；全对/全错都有正反馈文案
F3 增强（扫描后选定）
- F3.1 错题本「只看今日新增」筛选 + 掌握度环（视觉减负）
- F3.2 统计页加"错因趋势"小图（已有 errorTypeStats 数据，零新接口）
## 质量度量
- tsc 0 错；既有 76 断言不回退；新增 ≥20 断言全绿
- 冒烟新增：定制卷按钮可见/跟我练四步可走通（mock 级）
- 角色扮演：小满做错→定制卷→再练→错题闭环
## 风险红线
- 不改 generatedPractice/saveResult 既有判分路径（只增不改）
- 定制卷生成失败可重试，不阻塞原解析展示
- 参与式解题绝不调用大 token LLM（复用已落库的分析产物，0 额外 LLM 成本）
