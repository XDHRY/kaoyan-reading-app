# v5.8 整合方案 —— 阅读体验修复 + 任务可控 + 生图融入 SOP + 提示词提质

日期：2026-08-05 ｜ 基线：v5.7 (a5eda91)

## 问题清单与根因（按用户五条 + 数据佐证）

### P1 长难句解析置顶跳转
- 根因：长难句拆解用 `ink-modal-mask` 固定遮罩弹层，且页面动效容器带 transform 时 fixed 相对祖先定位，视觉上"跳到最顶上"，阅读位置感丢失。
- 方案：废弹层，改为**原位内联展开**——点击的句子下方就地插入拆解面板（加载/结果/错误三态），不离开阅读流；再点其他句自动收起上一个。

### P2 解析任务卡死不可控
- 数据佐证：库里现存 2 个僵尸 running 任务（最长自 08-03 卡至今）；历史 error 含"心跳超时/服务重启/503/内容审计"。
- 根因：`activeJob`/`pipelineStatus` 对僵尸 running 不做心跳判定，前端无限轮询"解析中"，用户无任何出口。
- 方案：
  1. 状态机扩展：`running/paused/done/error/cancelled`（drizzle 迁移加枚举值）。
  2. 新端点：`pausePipeline`（运行→暂停）、`resumePipeline`（暂停→续跑，复用断点逻辑）、`cancelPipeline`（任意未完成→停止）。
  3. 执行器每阶段写库前回读任务状态：paused→保存产物安静退出；cancelled→终止。
  4. `pipelineStatus`/`activeJob` 对 running 做心跳判定：>10min 静止自动转 error（"已自动终止，可重试"），前端永远看得到出口。
  5. UI：PipelinePanel 运行中加「⏸ 暂停 / ■ 停止」，暂停中「▶ 继续 / ■ 停止」，失败/停止「断点重试 / 关闭」。

### P3 AI 生图脱离 SOP、水墨结构图无意义
- 方案：废弃"水墨结构图"，重构为 **SOP 可选附加联想图**（不自动生成，两个独立按钮）：
  1. **全文景象联想图**：在结构分析之后，把 gist+各段 topic+logicFlow 提炼为一个具象场景提示词（帮助整体记忆与联想）。
  2. **核心词汇连锁图**：取文章关键词汇/术语，提示词精确描述节点与边的关系（因果/对比/递进/例证），画带标签的关系图。
  - 提示词不再限定水墨风，以"精确体现关系"为第一原则；缓存复用 analyses 表（modelUsed 标记区分）。

### P4 AI 生题缺历史解析入口
- 根因：HistoryPage 生成题行链接到 `/generate`（不带 id），永远回到空命题页。
- 方案：链接改 `/generate/set/:id`（路由已存在，GeneratedPractice 自动收养最近 done 任务恢复解析）。

### P5 统计缺真题/AI 分源评估
- 方案：`agent.stats` 增加 `bySource`：`exam`/`generated` 各自 {交卷次数, 判分题数, 正确数, 正确率, 近7天正确率, 题型分布}。
- UI：统计页 = 主模块（现有四图，综合两源）+ 两个子模块卡（真题 / AI 生题）；我的页面加同款三栏对照。

### P6 定位句跨段/主旨全篇
- 方案：agent_locator 提示词与输出契约扩展：`paraNos: number[]`（可跨段），主旨题允许 `paraNos=全部段`+`scope="全篇"`；`sentence` 允许两句并列。前端 QuestionAnalysisBlock 兼容渲染多段定位。

### P7 做题思路"很怪"（名师视角提示词提质）
- 扮演三位名师会诊：
  - **逻辑派**（唐迟式）：解题官必须先中文复述定位句含义→再比对选项，"阅读的本质是逻辑"，禁止跳步直接套条款。
  - **定位派**（颉斌斌式）：定位官强调题干-原文逐词对应，范围宁小勿大，例外才扩。
  - **语境派**（何凯文式）：解题官输入补"定位句上下文窗口"（前后各一句），避免断章取义；校验官以"证据-选项逐字对应"为准绳，不再为条款引用而打回。
- solver 输入从"只有 locate JSON"改为"定位句+上下文+题干"，methodRefs 降为可选佐证而非硬指标（1-3 条→0-3 条，禁止为凑数引用）。

### P8 使用记录推断的调整 + 公告致歉
- 工单佐证：「提交按钮点了没反应·操作太频繁」×5 —— 交卷限速 10 次/窗过紧，重试点击也被计入 → pipeline 限速放宽 + 重试不重复计数。
- 「顿悟室页样式疑问」×9 —— 已 resolved，无新动作。
- 任务控制上线后，由 admin 发布公告：致歉 + 优化方向与成果说明。

## 验收标准（verifier/v1）
1. 长难句点击后页面 scrollY 不变、面板出现在被点句下方（浏览器实测）。
2. 制造运行中任务→暂停→状态 paused 且产物保留→继续→done；停止→cancelled 且不可再轮询出 running；僵尸任务访问 pipelineStatus 自动转 error。
3. 结构分析块出现两个生图按钮，分别产出含关系标签的图片（或明确降级提示），缓存二次点击秒回。
4. 学习档案 AI 生题行点击直达该套题并恢复解析。
5. stats 接口含 bySource.exam/generated 且数字与 practice_records 对账一致；统计页/我的页三模块渲染。
6. 主旨题定位输出 paraNos 数组（真实 LLM 跑一篇验证）。
7. 全量回归（既有 6 套）+ 新增边界用例全绿。
