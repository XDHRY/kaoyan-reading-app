# 使用手册（纸上功夫 · 考研传统阅读助手）

本文档面向**使用者**（学生/备考者），按「从注册到复盘」的完整流程说明每个功能怎么用、什么时候用、以及常见问题的处理方式。界面细节以实际页面为准，这里讲的是「怎么用它帮你提分」。

> 适用版本：v5.11。若界面与本文有出入，以 CHANGELOG 的版本说明为准。

## 一、账号与登录

### 1.1 注册

- 打开首页点「注册」，填写：昵称（≤32 字）、密码（6~64 位）、密保问题与答案（用于忘记密码时找回，请牢记）。
- 注册成功即自动登录；头像默认取昵称首字，可在「个人中心」修改。

### 1.2 登录 / 找回

- 登录只需昵称 + 密码。
- 忘记密码：点「忘记密码」→ 回答注册时的密保问题 → 通过后设置新密码。
- 改密保问题：登录后进入「个人中心 → 账号安全」随时更换。

### 1.3 数据出口

- 「个人中心 → 导出数据」可一键导出你的全部学习数据（JSON 全量备份）。
- 同一个 JSON 可在「设置 → 导入备份」中恢复到新账号（策略可选：跳过已存在 / 覆盖）。

## 二、真题练习与六阶段解析

这是本应用的核心。打开「真题库」选一篇阅读文章，开始练习。

### 2.1 交卷与判分

- 逐题作答（每题四个选项），完成后点「交卷」。
- **判分唯一基准是官方答案**：有官方答案的题目按官方答案判对错；无官方答案时降级参考 AI 答案，界面会标注「AI 参考答案」。
- 交卷后自动进入六阶段解析（详见下），解析完成后文章会归档到「解析档案」，可随时回看。

### 2.2 六阶段解题流水线（SOP）

每篇文章按六阶段解析，全流程可实时查看进度、随时暂停/继续/停止，断点可重试：

| 阶段 | 做什么 | 你看到什么 |
|------|--------|-----------|
| 审题 | 定位每题的题型与考点 | 逐题题干 + 考点标签 |
| 定位 | 找出答题依据句（可跨段，主旨题全篇定位） | 定位句高亮 + 段号 |
| 解题 | 三位「名师」逐题给出推理链 | 逻辑派（复述定位句再比对）/ 定位派（逐词对应）/ 语境派（上下文窗口） |
| 校验 | 对解题结果复核、纠偏 | 校验意见 + 修正后的结论 |
| 解析 | 生成五段式解析（题干/原文/推理/选项/总结） | 归档进「解析档案」 |
| 归档 | 结果落库，进错题本/生词本 | 学习数据更新 |

### 2.3 长难句拆解

- 在解析页或阅读中，点击任意长难句可**原位展开**拆解面板（不跳转、不丢阅读位置）：
  - 主干提取 + 意群串联「考场顺读法」逐句顺读；
  - 拆解结果可再点其他句子自动切换。

### 2.4 联想图（可选）

解析完成后可按需生成两类配图（不参与判分，纯辅助记忆）：

- **全文景象联想图**：把全文主旨、主题、逻辑走向画成具象场景；
- **核心词汇连锁图**：关键词作为节点，标出因果/对比/递进/例证关系边。

## 三、跟我练（参与式解题）

不想一次交卷？用「跟我练」逐题走一遍六阶段：先看题干 → 自己定位 → 自己解题 → 逐题对答案。每步都会给参照（定位句/解题链），适合刷题期「边做边学」。

## 四、错题本与生词本

### 4.1 错题本

- 交卷判错（或 AI 生题判错）的题自动入册，记录你的作答与正确答案。
- 每条错题可做「错因分析」：错因六分法（审题失误/定位偏差/逻辑误判/词汇障碍/马虎/其他），并生成诊断洞察与练习建议。
- 「重练」重新作答，「标记已掌握」移出待练区。

### 4.2 生词本

- 阅读中长按/点选不认识的词 → 加入生词本，自动取释义。
- 可设置熟悉度（0~2：生疏/模糊/熟悉）、生成词汇记忆配图、随时移除。

## 五、AI 生题与定制卷

- 「AI 生题」：输入主题（如「人工智能与就业」）+ 难度，生成一套模拟阅读（含解析），进入后可像真题一样作答并判分。
- 生成历史在「历史记录」中留存，可直达题目集继续练习；复盘时可将做过的题编成「复盘定制卷」重做。

## 六、作文工坊

- 两种模式：
  - **接力引导**：分步进行——审题 → 列提纲 → 逐段生成 → 逐段确认，最后一键成文；
  - **一气呵成**：直接生成全文草稿，再按批改意见逐段「进化」修改。
- 批改：生成后调用批改官给出意见，可按意见继续迭代；素材库（个人语料）可先行保存，写作时引用。

## 七、统计

- 总览：练习量、正确率、近 7 天走势、题型分布；
- 分源统计：真题 / AI 生题各自独立看（交卷、判分、正确率）；
- 个人中心同款三栏，随时了解自己的进步曲线。

## 八、沉浸模式与深色模式

- **沉浸模式**：快捷键 `⛶` 进入无干扰阅读；`←→` 翻页、`1234` 选答案、`Enter` 确认、`Esc` 退出。
- **深色模式**：设置或右上角一键切换，夜间刷题护眼。

## 九、设置与 API 渠道

- **个人渠道**：在「设置 → API 设置」配置你自己的 LLM 渠道（中转站 / OpenAI 兼容均可）：名称、类型（对话/绘图/深度搜索）、协议、Base URL、密钥、模型与推理档位（temperature/maxTokens/超时/重试）。
  - 密钥只存服务端，前端只显示掩码；个人渠道只有你自己可见。
  - 普通用户只能建「个人渠道」；「全站渠道」仅管理员可管理。
- **角色绑定**：每个对话角色（解题官/命题官/错因分析师/拆句教练/作文三件套等）可选择「个人覆盖 → 全站绑定 → 默认回落」三级路由；「路由地图」页可一目了然每个角色当前实际走哪个渠道及来源徽标；「一键套用」可把当前绑定批量应用到全部角色。
- **连通性自检**：对每个渠道可点「测试」验证连通；「自检」会逐角色探测绑定是否生效。

## 十、管理台（管理员）

管理员（启动时 `ADMIN_PASSWORD` 指定，见部署指南）可进入管理台：

- 用户管理：列表/搜索/重置密码/重置密保/查看数据/清空数据/删除；
- 渠道与设置：管理全站渠道、全局设置项（键值）、SOP 条款编辑；
- 工单中心：查看/回复用户工单、发布公告（公告会显示在首页横幅与公告榜）。

## 十一、反馈与工单

- 页面右下角「反馈印」：点击可提交问题反馈（支持截图上传、附带最近 5 条前端报错），提交后生成工单号；
- 「个人中心 → 反馈与工单」可查看工单处理进度（状态随管理员回复更新）、继续补充内容或关闭工单。

## 十二、常见问题（FAQ）

| 现象 | 原因与处理 |
|------|-----------|
| 交卷后解析很慢/卡住 | 六阶段流水线受渠道响应速度影响；可在面板上点暂停/停止，或用「断点重试」续跑；单任务总时限 25 分钟，超时自动失败，可重试 |
| 提示「操作太频繁」 | 服务端限流（写库/LLM 端点每分钟有次数上限），稍等片刻再试 |
| 渠道「测试」失败 | 检查 Base URL 是否为 `https://` 开头、密钥是否有效、模型名是否正确；个人绑定是否正确路由（见路由地图） |
| 解析没有参考 | 「跟我练」若未先走完解析流程会提示「可用但无参照」，先完成一次完整解析即可 |
| 图片生成失败 | 该渠道不支持绘图或配额不足，换绑「绘图」类型渠道；生图与解析解耦，不影响判分 |

## 十三、隐私与安全须知

- 密码仅存 scrypt 加盐哈希；渠道密钥仅存服务端（数据库/环境变量），前端只显示掩码。
- 渠道 Base URL 强制 `https://` 且禁止内网/回环地址（防 SSRF），非法地址创建/修改时会被拒绝。
- 个人数据（错题/生词/作文/工单/个人渠道）严格隔离：**只能查看和修改自己的**，管理员可在授权范围内管理。
- 真题语料仅供个人学习使用，请勿公开分发。
